关于访问范围：
· 同一 WiFi / 局域网的电脑和手机，用「192.168.x.x」或「10.x.x.x」开头的网址即可访问。
· 校外或不同网络的人访问不了这些地址——需要先做内网穿透或部署到公网，见 部署指南.md。
· 若同一 WiFi 也打不开，通常是 Windows 防火墙没放行，需以管理员身份运行：
netsh advfirewall firewall add rule name="15栋社区智能体" dir=in action=allow protocol=TCP localport=8080

对方打不开？按顺序检查

  1. 确认服务在运行——看最上面的「服务状态」是否为绿色。
  2. 确认在同一网络——手机连的是不是和电脑同一个 WiFi？
  3. 检查防火墙——以管理员身份执行上面那条 netsh 命令。
  4. 确认网址没抄错——IP 可能因重启而变化，重新运行 node scripts/share.js 生成新的。
  5. 对方在校外——这些局域网地址对他无效，需按 部署指南.md 做公网方案。
