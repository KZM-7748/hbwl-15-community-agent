【最快上手】

  1. 安装 Node.js（https://nodejs.org，选 LTS 版，安装时勾选 Add to PATH）
  2. 双击  启动.bat
  3. 浏览器会自动打开，即可使用

  ★ 注意：必须先启动服务，再通过浏览器访问 http://localhost:8080
     不要直接双击 public 文件夹里的 html 文件（那样样式和校徽会加载失败）

--------------------------------------------------------

【三个入口】

  入口页   http://localhost:8080            选择学生端 / 教师端
  学生端   http://localhost:8080/student    问答、查通知、看活动
  教师端   http://localhost:8080/teacher    数据看板 + 知识库维护
  会议工具 http://localhost:8080/meeting    打开 WPS、会议模板、导出知识库

  教师端口令：hbuas2026
  ⚠️ 正式使用前请务必修改！见下方「使用前必做」。

--------------------------------------------------------

【会议工具（打开 WPS）】

  社区开会常用 WPS，入口：http://localhost:8080/meeting

  · 一键打开 WPS 文字 / 表格 / 演示
  · 下载会议模板：纪要、签到表、策划方案、值班表
  · 导出知识库为表格，开会查阅或打印

  ⚠️ 只能在一体机本机使用（用 localhost 访问）。
     其他设备访问时这些按钮不可用——浏览器不能远程启动本机程序。

--------------------------------------------------------

【使用前必做】

  1. 修改教师端口令
     编辑 data/_config.json，把 teacherPin 改成自己的强口令
     （或设置环境变量 TEACHER_PIN，优先级更高）

  2. 核实知识库内容
     运行 node scripts/selfcheck.js 查看健壮性检查
     运行 node scripts/deploycheck.js 做部署自检

  3. 如需让其他机器访问，以管理员身份放行防火墙：
     netsh advfirewall firewall add rule name="15栋社区智能体" dir=in action=allow protocol=TCP localport=8080

【怎么发给别人看】

  运行： node scripts/share.js
  会生成「分享给他人.html」，直接发给对方即可。
  对方用浏览器打开，能看到可点击的网址和可扫码的二维码。

  ★ 前提：对方需与本机在同一 WiFi / 局域网。
    校外的人打不开 192.168.x.x 这类地址，需先做公网方案（见如何分享给他人.md）。

  ★ 对方打不开？九成是防火墙没放行。以管理员身份运行：
     netsh advfirewall firewall add rule name="15栋社区智能体" dir=in action=allow protocol=TCP localport=8080

【教师端最常用：补充答案】

  同学问的问题如果智能体答不上来，会出现在教师端「数据看板 → 待补充问题」。

  点「补充答案」→ 问题已自动填好、关键词已抽好 → 只写答案 → 保存
  → 同学下次问同样的问题就能得到回答（立即生效，不用重启）。

  清单收录三种缺口：
    · 未命中    —— 完全答不上来
    · 可能答错  —— 答了但置信度低（如「校车几点发车」答成「宿舍几点熄灯」）
    · 被点没用  —— 同学点了「👎 没用」

  按缺口强度排序，被点「没用」的排最前（那是"答了但错"，最该修）。

--------------------------------------------------------

【备份很重要】

  教师端的删除不可撤销，误删无法找回。
  改内容前先备份：node scripts/backup.js
  查看备份：      node scripts/backup.js --list
  恢复：          node scripts/backup.js --restore <备份名称>

  备份自动保留最近 30 份，恢复前会自动另存当前状态（可反悔）。
